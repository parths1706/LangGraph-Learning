# LangGraph-Learning

A repository containing notebooks and code for learning and implementing workflows with LangGraph.

## Files Included
- `0_test_installetions.ipynb`: Jupyter notebook for testing installations.
- `1_bmi_workflow.ipynb`: Implementing a simple BMI workflow.
- `2_simple_llmworkflow.ipynb`: A basic LLM workflow using LangGraph.
- `3_prompt_chaining.ipynb`: Implementing prompt chaining techniques.
- `requirements.txt`: Python dependencies required for the project.
